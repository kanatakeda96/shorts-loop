日本語

1. 取得する情報

shorts-loop は、Google アカウントでの認可を通じて、運営者自身の YouTube チャンネルについて次の情報を取得します。チャンネルの ID と名前、投稿した動画の情報、動画の再生数などの統計です。

2. 使い道

取得した情報は、運営者のチャンネルへの動画の投稿と、運営者自身の動画の分析にだけ使います。

3. 保存場所

取得した情報と認可の記録は、運営者の手元のパソコンにだけ保存します。外部のサーバーには保存しません。

4. 第三者への提供

取得した情報を第三者に渡したり、販売したりすることはありません。広告にも使いません。

5. Google のポリシーの順守

Google API から受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

6. 許可の取り消し

許可はいつでも Google アカウントの「サードパーティ製のアプリとサービス」 から取り消せます。

7. お問い合わせ

English

1. Information we access

Through Google account authorization, shorts-loop accesses the following information about the owner's own YouTube channel: the channel ID and name, information about uploaded videos, and video statistics such as view counts.

2. How we use it

This information is used only to upload videos to the owner's channel and to analyze the owner's own videos.

3. Where it is stored

The information and authorization tokens are stored only on the owner's local computer. They are not stored on any external server.

4. Sharing

We do not share or sell this information to any third party, and we do not use it for advertising.

5. Google API Services User Data Policy

shorts-loop's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access

You can revoke access at any time from Third-party apps & services in your Google Account.
