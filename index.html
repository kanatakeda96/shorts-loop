shorts-loop

日本語

shorts-loop は、YouTube チャンネル「AIありなし比較」の運営者が自分で使うための個人用ツールです。

運営者が作成・確認したショート動画を、YouTube Data API を使って自分のチャンネルに予約投稿します。また、YouTube Analytics API で自分の動画の再生数などを取得し、次の動画づくりの参考にします。

一般の方に向けて公開・提供しているサービスではありません。運営者以外のアカウントのデータを扱うことはありません。

English

shorts-loop is a personal tool used only by the owner of the YouTube channel "AIありなし比較" (AI Ari Nashi Hikaku).

It uploads and schedules short videos, created and reviewed by the owner, to the owner's own channel via the YouTube Data API. It also reads view counts and other statistics of the owner's own videos via the YouTube Analytics API to improve future videos.

It is not offered to the public and does not access data from any account other than the owner's.
